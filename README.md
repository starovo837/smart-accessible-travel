# 智能无碍行

React 19 + TypeScript + Vite 无障碍生活与出行 Web App，含商品解读、三维试配、出行清单与学习支持中心。

## 体验与启动

在线体验可打开[魔搭创空间](https://www.modelscope.cn/studios/starovo/smart-accessible-travel?mode=full)。

本地需要 Node.js 24 和 pnpm。进入仓库后运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://127.0.0.1:5173/。可用 `pnpm build` 构建网页与离线壳，用 `pnpm test` 跑自动化测试。商品页内有预置案例。实时图文解读需要配置本地推理服务，详见[本机使用说明](desktop/README.md)。

## 校园封面与水景

0.6.2（2026-11-21）的工作台顶部是全宽校园封面，高度为 `clamp(260px, 40svh, 400px)`。校徽在封面最右侧，前两组入口排在鼓励卡之前。桌面两侧仍可见静态校园照片，喷泉只在首页封面播放。「我的 → 辅助设置」可以关闭「背景水景动效」。「减少动画与滚动效果」、系统减少动态（`prefers-reduced-motion`）、老年模式、省流量或系统高对比度下，封面只显示静态照片。切到后台或封面离屏时停止绘制并清空画布。开发服务器的 `?calibrate=fountain` 可调整喷口、池面和封面裁切。

新建三维试配默认展示无辅具站姿。用「切到轮椅坐姿」查看屈膝坐姿和脚踏接触，再用「切到站姿」返回。切换时保留填写的身体尺寸。开发服务器的 `?fitDebug=1` 可在控制台查看双侧膝角、鞋底倾角和最低点。

出行、学习与生活服务页面会写明哪些内容看过官网、什么时候看过，以及哪些条件还没确认。出行日期、官网链接和承运方的书面确认提示均保留。应用构建会检查界面用词。封面截图、性能及上线状态见[工作台与校园主题](docs/工作台与校园主题.md)。

## 魔搭新访客会话（2026-11-19 已部署）

从已部署的 0.6.0 起，可信代理模式每地址最多保留 64 个会话。共享网关的会话总数只受全局 2,000 个上限约束，每地址每分钟最多签发 60 个。全局待使用会话最多 500 个，有效期为 5 分钟，容量受限时优先释放最早的待使用会话。业务接口另计。`/api/status` 的 `sessionIssuance.sessions` 显示进程内当前有效会话总数。公开入口已实测 65 个独立访客均正常取得会话。[0.6.0 线上验收](docs/界面文案与动效-2026-11-19.md)

## 日常交互与隐私 E 批（2026-11-18）

生活步骤的勾选框可读出步骤名。26 条服务渠道均显示「信息更新于」与官网链接。就医地图之后可查中国康复研究中心与北京 114，两个渠道均标明北京范围及需自行核实。常用话语可逐条删除。

纠错可逐条删除。关闭设备资料保存会撤销含设备资料或承运方记录的分享，纯清单分享保留。关闭生活资料保存会清除本机常用话语、步骤进度、提醒等辅助记录及学习记录。撤销或本机写入失败时保留授权与管理记录，可重试。

打开限时求助时核验管理凭据。朗读使用设备上的中文音色，播放失败会展示大字卡。出行「朗读全部」包含行程摘要、各阶段、通用建议和联系人。详见[日常交互与隐私 E 批](docs/日常交互与隐私-E批实现与验收.md)。

## 会话与限流 D 批（2026-11-18 基线）

有效 Cookie 或 `X-Sai-Session` 可复用会话。在本地和可信代理模式中，每个客户端地址每分钟最多签发 6 次，最多保留 64 个会话，其中未使用会话最多 6 个。共享网关的额度见上节。触限返回 HTTP 429 和 `Retry-After`。业务接口按地址和操作类型合计额度。

Cookie 使用 `HttpOnly`、`SameSite=Strict`、`Path=/`，HTTPS 增加 `Secure`。代理部署需核实可信网关后配置 `SAI_TRUSTED_PROXY_IPS`，缺省按直连地址计数。部署仍待确认魔搭实际网关与客户端地址转发行为。详见[会话与限流 D 批](docs/会话与限流-D批实现与验收.md)。

## 档案授权整改 C 批（2026-11-18，本地）

只有 `consent === 'granted'` 且 `privacy.profile === true` 才保存类别、等级、陪同及主要辅具引用。未授权、暂不填写或关闭档案保存时，选择仅用于当前运行；启动会清除遗留档案键。授权后可保存并刷新恢复。

撤回档案保存、删除个人档案或全部资料，会清除独立档案键、主快照的分类与页面选择。出行缓存也会清除类别/等级和组合建议，避免刷新或离线时重新出现；普通行程、设备和生活资料继续按各自授权保留。清除失败会显示错误、阻止授权切换或关闭删除对话框，不报告成功。重新授权不会复活旧选择。

C 批构建和全量316项测试通过，新增16项隐私反例；Chrome/WebKit通过类别等级恢复、未授权缓存、撤回、删除失败重试及320px/200%字号检查。真人读屏与手机真机仍待验。详见[档案授权 C 批](docs/档案授权-C批实现与验收.md)。

## 设备证据整改 B 批（2026-11-18，本地）

设备草稿与逐项确认一同保存。只有 `confirmed[field] === true` 且非样例的尺寸、重量、电池、折叠资料能进入出行判定。选择“我的设备”会带出普通待核对资料，页面显示“待核对 / 去核对”；更改任一值会撤下该项确认，逐项核对后即时重算。保存资料不等于确认资料。

预置商品和模拟铭牌资料不能标为已核对；设备卡保留样例来源，出行侧不读取样例值。旧出行快照无确认信息时保留普通草稿，撤下原数值判定、原勾选与比较记录，重新生成准备清单，并提醒核对；断网也不会复用旧的“完整”结论。真实设备确认后可保存并刷新恢复。

B 批本地构建与全量300项测试通过；Chrome/WebKit完成核对、修改、刷新、样例禁用及320px/200%字号检查，真机与真人读屏仍待验。详见[设备证据整改 B 批](docs/设备证据-B批实现与验收.md)。

## 规则核验整改 A 批（2026-11-17，本地）

规则目录含铁路携带品、国航辅助设备和国航轮椅电池 3 条入口。没有人工记录时，页面显示「有 0 条对照过官网（共 3 条）」。清单仍有准备建议、官网和电话。「更新条款记录」读取已保存的记录，「重新查看官网」打开官网页面。

本地运行 `node scripts/review-rules.mjs --check` 只比对原文，不写文件。核查人阅读全部条款后，须自行提供 `--reviewer "工作代称" --note "核查范围与结论"` 才能写入 `SAI_DATA_DIR/rules.json`（未设置目录时为 `.app-data/rules.json`）。全部摘录匹配才批准对应记录，有效期7天；原文变化、读取失败、过期均不能作为现行限值。刷新不会延长人工核查日期。

部署可选读取 `deployment/modelscope/rules.verified.json`；只有含人工核查信息且与目录一致的记录能打包。缺少或无效时启动为未核验目录，不自动抓取。A–E 批已发布，11 月 19 日线上仍显示 0 条对照过官网的条款。范围、回滚与验收见[规则核验整改 A 批](docs/规则核验链路-A批实现与验收.md)。

## 学习支持中心（0.5.0，2026-11-16）

- 首页“办事与参与 → 学习支持中心”单击进入；“生活 → 学习工作”顶部也有资源预览。
- 18 条资源，六类各 3 条。可搜索或按类别、无障碍支持、地区、费用筛选，也可按推荐、最近使用和最近更新排序。
- 资源卡的日期是本应用查看公开信息的时间。记录超过 90 天会提示「可能已过期，用前再确认」。课程是否无障碍、是否招生及是否可用，请打开来源查看。
- 收藏、问题标记、目标、1–3个资源组成的计划、步骤、进度与笔记；计划复用逐步任务和站内提醒。可导出不含私密信息的离线清单、SVG随身卡和ICS日历文件。
- 12张合理便利申请模板、6张工具教程。申请需由正式受理方决定；本工具不收集证明材料、不判断资助资格。

学习记录仅在当前浏览器运行；开启“生活资料保存”后持久化，沿用保留期限。关闭授权、清除学习记录、删除生活或全部资料会清除学习数据及关联任务和提醒。笔记、学习目标原文、障碍信息不进入学习导出、普通分享或日志。

站内提醒只在网页运行时检查到期，不保证网页关闭后的送达。日历文件须自行导入手机日历。未逐个实际试用第三方课程；未声明的字幕、读屏、手语等支持均标未确认。没有抓取课程、自动报名或就业承诺。

## 运行与验证

Node.js 24 或支持原生TypeScript擦除的版本；安装依赖后运行 `npm run dev`。构建 `npm run build`，测试 `node --test tests/*.test.mjs`。本工作区也可用 `pnpm run build` 执行同一脚本。

本次新增目录/链接/复核状态/计划保存恢复/撤回删除/导出隐私测试。浏览器验收结果及真实设备未覆盖范围见[学习支持中心实现与验收](docs/学习支持中心-实现与验收.md)。

服务渠道目录仍为26条；学习目录单独18条，包含原有就业、智慧教育与盲人数字图书馆入口，不能简单相加当作44个不同服务方。
