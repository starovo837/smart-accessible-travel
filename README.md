# 智能无碍行

面向视障、残障群体的辅具商品 AI 信息解读与出行合规查询助手。

将商品文字、说明书或详情截图变成带原文依据的参数、冲突和缺项，再结合本人确认的设备数据核对居家适配与出行条件。支持文字放大、键盘操作、朗读、沟通卡、逐步引导、离线随身包与限时家属分享。

新增“三维试配”独立页面：可以拖动旋转、缩放人体与轮椅、助行架、拐杖、盲杖、助听器及腕踝支撑的三维组合；填写身体尺寸、调整示意结构，从独立的“买辅具”页面比较有来源的候选商品，从“出行查询”页面核验实物设备。首页同一组入口还包含“日常辅助”和“文字助手”。自然人物带面部、皮肤、头发和衣着；坐姿、站姿仍为近似比例。三维是参数化示意，不能证明医学适配、承重或制造可行性；没有人体扫描或结构力学仿真。可导出GLB、视角PNG和方案JSON。

身体尺寸默认只在本次内存中使用，另行启用本地自动保存后可恢复；不交给商品AI、购物平台或家属。购物平台提供一般辅具搜索入口，候选款式由本人加入或从已有解读导入，不宣称实时抓取全网商品。资料不足时保持未知，不计算无依据的适配百分比。示意座宽、人体体重与实物外宽、设备重量严格分离，只有本人明确核对的实物资料进入出行核验。[三维功能实现提示语](docs/三维量身选辅具-实现提示语.md)。

## 体验

### 会话与限流（2026-11-19 已部署）

已有有效 Cookie 或 `X-Sai-Session` 的状态查询继续复用。可信代理模式每地址最多保留 64 个会话。共享网关的会话总数只受全局 2,000 个上限约束，每地址每分钟最多签发 60 个。全局待使用会话最多 500 个，5 分钟后到期，满时优先释放最早的待使用会话。`/api/status` 的 `sessionIssuance.sessions` 显示进程内有效会话总数。业务接口另计。已部署的 0.6.0 通过 65 个独立访客的线上验证。

容器处于反向代理后时，默认按直连网关 IP 计数。只有确认网关在 `X-Forwarded-For` 末尾追加直接上游或覆盖该头，且服务入口受控，才在 `SAI_TRUSTED_PROXY_IPS` 填写经过核实的代理 IP，多个以逗号分隔。若有多跳，只填写确认为可信的网关。填写 `SAI_PUBLIC_ORIGINS` 为仅 HTTPS 的公开网址时，应用 Cookie 带 `Secure`，包括浏览器未发送 `Origin` 的状态请求。实际魔搭转发契约与线上流量隔离仍待验证。详见[会话与限流 D 批](docs/会话与限流-D批实现与验收.md)。

### 个人档案授权（C 批，2026-11-18）

类别、等级仅在本人授权且开启档案保存后写入浏览器。未授权或暂不填写仍可临时选择使用，刷新不恢复；启动清除遗留档案记录。撤回或删除时清除独立档案键、主快照分类与页面状态，同时移除出行缓存中的分类建议，保留普通行程与设备数据。失败会报错并阻止授权切换；重新授权不恢复旧分类。

该说明描述本地待发布源码，不代表创空间已同步。C批未修改后端会话、限流、第三方服务和三维生成算法；真实浏览器与设备仍需人工验收。见[档案授权 C 批](docs/档案授权-C批实现与验收.md)。

### 设备字段确认（B 批，2026-11-18）

普通待核对资料可在本机回填，但只有逐项确认且非样例的尺寸、重量、电池与折叠状态进入出行比较。修改一项就撤下该项确认；保存设备卡不自动确认。预置商品和模拟铭牌保留样例标记，不能勾选成实物资料，请新建实际设备。

旧出行快照没有确认记录时，移除旧数值结论、勾选和比较记录，保留普通草稿与官方入口；离线也会重新生成准备清单，提醒核对。无需登录，沿用本地存储与删除。三维几何计算没有改动。此说明描述本地待发布源码，不表示创空间已同步；验收见[设备证据 B 批](docs/设备证据-B批实现与验收.md)。

本轮更新：分类使用视力残疾、听力残疾、言语残疾、肢体残疾、智力残疾、精神残疾，可同时选择多类；“多重残疾”由选择结果显示。等级、陪同情况和主要辅具引用选填，保存在当前浏览器。分类与等级不用于资格或优惠判断，不采集证件号码、证件照片或病历。

出行清单保留 A–E 五段与完成度提示。生产行动目前配置流程冲突，单独展示替代提醒及原因；通道与相反指令仅在通用引擎及合成测试中支持，未配置到生产行动。清单提供官方入口、电话、问法、导出与随身卡。首页和“我的”提供关于页，清单默认展开。真人听读和外部人员复述尚未完成。详见[分类与复合出行实施记录](docs/法定分类与复合出行-实施记录.md)。

### 条款核验记录（A 批）

规则目录3条（铁路1条、国航2条），另有11个咨询/交通/监督来源，合计14个来源入口。14不是已核验条款数，服务渠道目录则是26条，两种目录不混算。页面显示有效核验数；0条时明确仅为通用准备建议，保留官方链接、电话和问法。

`node scripts/review-rules.mjs --check` 仅在本机检查全部摘录，不批准、不写盘。人工阅读原文后提供 `--reviewer` 和 `--note` 才能批准匹配记录，7天后到期；抓取或用户点击更新都不会续期。单次下载15秒、2MB，拒绝重定向。

发布前可在源项目放置人工核查的 `deployment/modelscope/rules.verified.json`。整理器严格校验，生成 `server/bundled-rules.verified.json` 随既有server白名单进入镜像；该位置不可放手工文件。启动器优先读取直接部署的同名文件，否则读镜像副本，复制到数据目录rules.json。未提供文件或文件无效时回到3条未核验入口，不抓取、不自动批准。旧版无核查人/说明的自动批准记录在读取时降为未核验。

本次没有附带生产核验文件。代码本地通过不代表创空间已更新。详见[规则核验链路 A 批](docs/规则核验链路-A批实现与验收.md)。

1. 选择辅助版块，也可暂不填写。未授权保存时，个人档案只在当前运行中使用。
2. 进入“买辅具”，粘贴公开商品文字或上传清晰参数图，勾选本次处理授权后开始。
3. 核对原文、型号、尺寸状态和冲突；仅本人确认的参数可用于后续设备卡与出行核验。
4. 进入“出行查询”，选择交通方式和设备，逐项补充信息；阅读适用范围、条件及官方来源。
5. 也可先看标明“预置案例”的合成资料，案例未调用模型。

## 真实 AI 与处理位置

容器内运行 Ollama 与 `qwen3-vl:4b-instruct` 开源图文模型，无需 OpenAI 或其他模型 API 密钥。构建阶段从官方仓库下载固定版本权重并校验清单、大小与 SHA-256；模型随镜像发布，启动时不再后台下载。用户主动授权的资料通过 HTTPS 发送至本创空间，模型推理只连接容器回环地址。商品原图、全文和问答不写入长期服务端档案。不要上传病历、证件或联系人等敏感内容。

参数提取后，程序继续检查单位、引用、型号和使用／折叠状态；模型输出不直接当作运输许可。带依据助手仅选用当前资料的有效陈述，不能自行编造政策。模型未就绪或失败时会明确提示，不冒充固定答案。

解读以后台任务运行，页面显示实际处理阶段及等待时间，避免长推理被网关超时截断；可随时取消。任务绑定当前浏览器会话，仅在服务内存中暂存，完成后最多保留10分钟；取消后清除，页面失联超过90秒会停止任务。刷新或关闭页面不会生成可再次访问的公开资料链接。图片只进行一次视觉转写，再依据转写文字提取参数。

## 当前边界

- 当前正式规则覆盖范围以页面显示为准；其他交通方式可生成准备建议，不能据此推定许可。官方来源失效、变更或过期时保留待确认状态。
- 情况录入采用手动选择，助手采用文字输入；设备铭牌交互含模拟环节，朗读能力依设备而异。
- 没有账号体系。个人档案经本人授权后保存在当前浏览器；主动提交的纠错、限时分享按各自授权存到服务端，可撤销或删除。服务端磁盘加密不等于端到端加密。
- 实际读屏、残障用户独立操作及不同手机上的体验仍需人工实测。
- 免费资源有额度、休眠和容量限制，不能保证持续在线或推理速度；CPU 上首次解读可能较慢。

每个结论页均显示：**仅供参考，以承运方书面确认为准**。

## 运行与维护

Docker 构建前端，Node.js 24 提供 `0.0.0.0:7860` 的同源界面与 API，Ollama 只监听 `127.0.0.1:11434`。容器按免费 CPU 规格保留 CPU 推理组件，不打包 GPU 后端。本机管理、规则审核与手机配对端点在线上全部关闭。

模型随镜像存放在 `/opt/smart-models`，授权协作资料和规则核验缓存在 `/mnt/workspace/smart-accessible/data`。按魔搭当前持久化约定维护；迁移、改名或平台调整仍可能影响数据，请妥善保留用户导出的管理凭据。

若反向代理重写 Host，在创空间变量中将 `SAI_PUBLIC_ORIGINS` 配置为实际应用的 HTTPS origin（多个以逗号分隔，仅协议与域名，无路径）。不接受任意来源，不根据不可信转发头开放权限。

创空间应用网关不放行 DELETE。客户端通过 POST 加 `X-Sai-Action: delete` 提交任务取消、纠错删除和分享删除；服务器仅允许对应的对应路由，并继续校验来源、会话或每条记录的管理凭据。

上传目录经过白名单整理，不含 `.env.local`、本地用户记录、密钥、模型权重、Git 历史或其他项目。不要把平台上传令牌写入创空间变量或代码。

日常辅助参考 [Hello AI](https://github.com/fuwawas/hello-ai-accessibility)（MIT，许可见 docs/third-party/hello-ai-LICENSE.txt），包括本机颜色/明暗判断、文字朗读、大字卡和自定义步骤任务。摄像头需HTTPS或localhost；所有输入采用手动选择、文字或图片，不提供录音、语音转写或语音导航。没有避障和完整手语识别能力，不以规则或预置答案冒充这些能力。照片不保存不上传；生活任务与进度按现有生活资料授权保存，可从隐私设置删除。

本次扩展为分类辅助平台：选择六类辅助需要后首页推荐对应工具，多选合并，所有19项工具始终可见。新增真实开源图像阅读、MediaPipe本机基础手势与练习、放大镜、自设提醒；任务和常用话语按生活资料授权保存。体重现在会改变三维人物的近似体型，不生成实测围度。详见 [分类辅助平台实现与验收](docs/分类辅助平台-实现与验收.md)。


## 生活服务

### 学习支持中心（0.5.0，2026-11-16）

首页“办事与参与”直接打开学习支持中心；学习工作场景顶部也有资源预览。独立目录18条，六类各3，含官方资源、机构咨询、软件工具与政策说明，并非18门课程。可检索、组合筛选、收藏、朗读介绍、查看来源和90天复核日期。字幕、手语等未确认的能力不作承诺。

先选目标类别，再填写具体目标，每个学习计划可选1–3资源，并同步至既有逐步任务。学习进度、笔记和站内提醒仅在本机；开启生活保存后刷新恢复，撤回或删除则清除。导出TXT、SVG随身卡与ICS日历不含私密目标、笔记或障碍信息；关闭网页后不保证站内提醒送达，日历须本人导入。

另有12张学习便利申请模板及6张工具教程，不代报名、不判断获批或资助资格，不上传证明材料。[学习支持实现与验收](docs/学习支持中心-实现与验收.md)、[核验台账](docs/学习资源核验台账.md)、[候选池](docs/学习资源候选池.md)。

首页及底部“生活”新增去医院、出门办事、在家生活、学习工作、参加活动、获得协助六个场景，对应地图与设施、就医、限时求助、福利办事、辅具专业服务、数字办事、居家联动、学习工作与休闲八项服务。普通生活资料按既有生活保存授权实时存入当前浏览器。

真实机构目录 26 项，服务卡展示范围、「信息更新于」和来源。预约与人工联系在原平台完成，本站只记录本人提供的回执。居家联动提供兼容准备、厂商入口与本机测试。常用话语及纠错可逐条删除，关闭设备授权会撤销相关分享，关闭生活保存会清除生活辅助记录。详见[日常交互与隐私 E 批](docs/日常交互与隐私-E批实现与验收.md)。

限时求助在当前服务内存真实创建15/30/60分钟链接，接收方主动回应、本人查看回执、到期或撤销停止访问。创建前逐次预览和授权，位置为可选的一次读取；没有自动发送消息或救援派单。普通离线导出排除求助管理和查看令牌；撤回生活保存或删除相关资料先撤销服务端求助。服务重启清空这些短期链接。

地图默认使用高德/百度地点搜索与本人的通行档案；主动同意后可加载OSM底图和Overpass真实公开设施查询。外网可能超时，不以模拟设施替代；地图标记不能证明电梯当前可用或路线可达。读取时间、原始核实日期与本人核实条件分别保留。详见[生活服务实现与验收](docs/生活服务-实现与验收.md)与[真实服务渠道核验](docs/真实服务渠道核验.md)。


## 按位置找医院与界面细节

就医协助主动申请一次浏览器位置，查询 2/5/10 公里内医院和诊所公开地图记录，可将选中的医院带入就医准备。拒绝定位或手机使用非 HTTPS 连接时，可手动填地区，经国内地图查找。地图之后另列中国康复研究中心和北京 114，均标为北京渠道并提示自行核实。百度周边入口使用 WGS84，高德在图内标点后搜索。位置只在本次页面使用，服务端公开结果缓存 10 分钟。号源、科室、协助和通行条件需向医院确认。

真实公开医院源可能不可用，本轮公开上海坐标请求返回上游不可用，未取得真实医院列表；不以固定北京名单或模拟医院替代。定位成功后，国内地图附近入口立即可用；界面成功、拒绝定位和失败分支已使用合成位置与资料验收。

六个场景与八项服务改用医院、房屋、书本、地图、握手等语义图标。部分页面按日期稳定显示一句温和短句，无弹窗或自动播报，可收起或在辅助设置中关闭；显示偏好仍按现有浏览器保存授权处理。


## 分类工作台与校园主题

打开即进入分类工作台，分为辅具与出行、阅读与沟通、生活与健康、办事与参与、地图与求助、我的与设置6组。辅助中心现有19项工具可自由使用（含学习支持），工作台入口数由实际目录构成。无需先填写个人情况；辅助组合在“我的”中调整，老年模式与朗读保留原设置。语音输入、实时字幕与语音操作继续移除，保留文字助手、沟通卡和朗读输出。
