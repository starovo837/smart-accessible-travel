# 评审证据的使用与复核

本文仅供开发复核。软件内已移除评审、案例测评、试用记录与开发工具入口；本页和已有测试数据不打包进日常应用。

## 公开商品案例

使用 [WHILL 中国官网 Model C2 页面](https://whill.cn/model-C2.html) 的短参数摘录，2026-10-18核对。型号和中国地区版本不与海外配置混用。页面的高度范围和约重不转写成测量事实；没有铭牌Wh就保持缺项，不用V×Ah补齐。

60cm入口为模拟情境，不是实际参与者资料。开发人员可从资料文件复制文本，通过正常商品解读、设备卡及国航查询流程复核。没有实际购买、个人试用或登机回执，不宣称真实出行成功。

运输部分引用 [国航特殊旅客服务方案](https://m.airchina.com/ac/c/invoke/specialAssistance@pgzhcn?comeFrom=xlxx)，具体适用仍由规则服务按当前有效期核验。不是其他承运人的规则。电动工具托运、客舱要求与电池要求分别检查；仅供参考，以承运方书面确认为准。

## 可复现AI对照测评

数据和人工标注在 `src/app/evaluation.ts`；共8例，7例合成资料、1例公开商品摘录。包含输入、指定评分字段、逐来源标准值、关键字段与禁止臆造字段。数据为开发人员标注的开发集，尚无第二位独立标注员复核、盲测留出集或图片OCR基准，不代表泛化水平。

运行本机服务与本地图文模型后，执行 `pnpm evaluate:ai`。脚本固定访问127.0.0.1:5173，顺序调用本机AI，不读取密钥，不调用云端，不自动重试失败请求；保留服务限流间隔。运行结果写入开发资料 `src/app/evaluation-run.json`，不进入软件界面或发布包。

`audit/evaluation-before-hardening.json` 保留首轮真实输出：曾出现诱导指令参数被采纳、尺寸分隔符误识别成型号和宽度顺序不被支持。开发集暴露后增加了指令上下文拦截与尺寸范围/顺序校验；复测不能当独立测试集。当前记录保留漏提取，不选最好的一次冒充全量。

评分对象是经过应用引用校验的结构化模型输出，不是原始token流。按来源、字段和值精确匹配，只评分该例标注字段。未标注字段不计入精确率；不支持的数值被拦截后列为拒绝项，不能算成功提取。分母为0显示不适用。关键漏项与禁止字段被采纳单独列出，不被平均分掩盖。失败记录不进入成功例分母，但单独显示失败数。

规则和AI处理相同输入；机器耗时只是本次本机处理时间，不能据此宣传用户省时。用户人工阅读对照需按下节实测，避免学习顺序干扰。新资料应先由两位标注者独立标注并解决分歧，再冻结为留出集，不能一边调参一边声称独立验收。

## 真实用户试用准备

开发资料 `src/app/evaluation.ts` 的 `studyProtocol` 保留形成性试用方案，含自愿同意、可访问说明、可随时停止、4类任务与成功标准、人工/规则/AI轮换顺序、研究员提示和安全干预的计数方式。软件内不再设置研究工具。

建议首轮招募6至8位自愿成年参与者，覆盖视障、听障、上肢受限及叠加需要；按实际辅助方式分别报告，不把少数人结果概括为所有残障者。没有招募、外发邀请或真实参与者数据被自动生成。

研究员应另行记录每次任务的参与者代号、设备/读屏版本/字号、输入方式、对照条件、资料编号、任务、日期、耗时、协助、误解、关键错误、1–5主观易用评分与反馈。有协助、误解或关键错误时不能计为独立完成。

外部研究记录由研究团队按参与者同意范围保管，软件内的删除操作不管理这些外部文件。仓库中保留的合成/公开测评记录不含个人资料。

当前真实用户证据状态：**待招募与实际执行**。浏览器自动化验证是技术验证，不是盲人、听障者或读屏用户试用结果。需要参与者和研究员实际完成任务后才能发布独立完成率、时间改善或用户评价。

## 本版本实际记录

v2同组复测：本机 `qwen3-vl:4b-instruct` 完成8例，标注范围内正确25项、漏1项、错误采纳0项，精确率100%、召回率96.2%；规则对照正确20项、漏6项、错误采纳0项，召回率76.9%。仍漏掉一次“电池可拆卸”：模型给出的引用只说电池数量，程序拒绝采纳。不能据此把缺失值填成“可拆”。

首轮v1为22项正确、4项漏提、2项错误采纳（诱导资料数字），精确率91.7%、召回率84.6%。前后均是同一开发集，不是公开排行榜、商业准确率承诺或独立评测结论。应用校验阻止了部分模型错误，但模型本身仍会生成原文不支持的字段；实际产品继续要求核对依据和缺项。
