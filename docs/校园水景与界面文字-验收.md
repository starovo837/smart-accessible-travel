# 2026-11-19 本地验收

## 阶段 0 · 会话

现有代码能配置可信代理。魔搭的公开说明未提供客户端地址追加约定或可信网关地址清单，当前采用宽松签发路径。临时会话按地址每分钟最多发 60 个。地址与全局上限分别为 64、2,000，全局未使用上限为 500。容量受限时优先清理最早的未使用会话。在已使用会话占满时，继续返回限流及等待秒数。可信代理和本机模式保留原有阈值。

回环 HTTP 通过同址 10 个独立访客的签发及逐个复用测试。额外测到第 61 次会限流、上限不超额、淘汰不会删除已使用会话。签发和业务使用独立的计数空间，`/api/status.sessionIssuance` 只含进程内汇总。401/429 有 `Retry-After`。上线后用十个独立访客请求公开接口，首次签发合计用时 3.79 秒，后续请求均复用原会话。
