# 界面文案与动效 0.6.0

## A · 首页封面带

东南大学四牌楼照片移到工作台页头下方。封面带独立于正文，使用原图和 Canvas 2D。高度为 140–200px，底部 24px 接回纸面。原喷泉坐标保留，封面带的纵向裁切位置为 0.80。

基础封面带截图为 `home-320.png`、`home-390.png` 和 `home-1440.png`。最终布局把寄语移到「辅具与出行」之后，实际构建的 320×740 截图为 `home-final-320.png`。三维试配、买辅具、出行查询和辅具专业服务四个入口均完整显示在底部导航上方，无横向滚动。

320px 放大到 200% 字号仍无横向滚动。390px 截图抽样对比度上升，标题由 11.47:1 至 11.67:1，说明由 7.09:1 至 7.21:1，首个按钮文字由 9.73:1 至 9.84:1。Chrome 稳态采样每秒约 22 次绘制，未记录到超过 50ms 的长任务，画布 DPR 上限为 2。

浏览器实测关闭水景、应用内减少动画、系统减少动态、老年模式、省流量及系统高对比度均显示静态照片。模拟标签页进入后台和把封面带滚出视口时，画布均已清空。

Chrome 390px、WebKit 320px 分别切换六个主要页面，验证焦点、Tab、无横向溢出及出行入场时点击返回。页面入场为 240ms，出行与商品输入为 160ms。

开发标定页已实测。拖动纵向位置滑杆时，照片与框同步移动，JSON 输出随之更新。截图为 `band-calibration-390.png`。
