# 可直接交给研发或编码助手执行的提示语

请在「智能无碍行」现有 React + TypeScript + Vite 项目中实现“量身选辅具”连续工作页，沿用高对比温和蓝、米白背景、大按钮和现有隐私控制。核心是一个真正由 Three.js/WebGL 渲染、可拖动旋转和缩放的人体与辅具三维场景，不能以固定图片、视频或假旋转替代。默认先展示标明为示例比例的全身中性人体，选择轮椅时可坐姿预览。用户填写身高、体重、坐姿臀宽、臀后至膝窝长、膝窝至足底高、肩宽、前臂长、腕围、踝围、足长等资料后，已知尺寸驱动对应几何；空白尺寸只能用于明确标记的示意比例，不得伪装成实测或三维扫描。体重不用于推断围度。支持左右侧和多辅具组合、正/侧/背/俯视、键盘转向与缩放、复位、文字描述和 WebGL 不可用时的明确降级。不要默认自动旋转。

首版实现手动轮椅、助行架、前臂拐杖、盲杖、耳背式助听器、腕部支撑、踝部支撑的参数化示意。轮椅座宽、座深、座高、靠背高、握把高及腕托长度可独立调整。模型显示佩戴位置与人体姿态；不得宣称接触面、皮肤压力、承重、活动范围或医学适用性已通过仿真，不生成制造级图纸或治疗处方。提供可携带的方案 JSON、三维 GLB 示意与视角 PNG 导出。方案须带单位、来源、未知项和非生产用途标记。

“三维试配、商品比较、出行核验”放在同一个工作页，切换时保持人体、辅具及草稿，接入原有真实商品 AI 解读和出行规则服务。商品比较优先复用已有解读结果，并允许加入实际候选的链接、座宽、座深、标称承重、外尺寸、重量、来源和核对状态。区分座宽与整机宽度；不从商品外观、用户评价或其他型号补齐缺项。京东、淘宝、天猫入口仅发送一般辅具搜索词，不把人体尺寸、残障情况或诊断放进搜索 URL。未接入授权商品 API 时，不宣称已经实时抓取、自动买到或选出全网最佳，也不编造款式、价格、库存和适配百分比。仅按有依据的已知参数显示一致、差异和待核对；未知项不加分，体重超过厂家标称承重的候选必须突出显示并排除推荐。

出行使用“已核对的实物外尺寸、设备重量、电池与来源”，与三维设计参数、座宽、人体身高体重完全隔离。预览方案不能自动成为已确认设备卡或携带许可。用户明确填入并核对实物资料后才传给原有设备卡与出行核验；没有规则或参数时明确保留未知，不默许可带。结论继续保留原有官方来源、更新时间和“仅供参考，以承运方书面确认为准”。

实时保存指在本人明确启用后，约600毫秒防抖保存此浏览器中的尺寸、视角、辅具组合、设计参数与候选，不默认上传身体资料到云端。显示保存状态及失败原因，支持刷新恢复、临时模式、显式导入导出、撤回保存授权和二次确认清除；全应用删除身体档案/全部数据时同步清除该草稿。不能将示例尺寸偷偷保存为本人数据，也不将身体资料纳入家属分享或 AI 请求。代码、提示语与变更说明作为普通项目文件随编辑保存。

实施时保持代码分层：数据和比较规则独立于三维几何与 React UI；释放 GPU 几何、材质、监听器、控制器与 WebGL 上下文，避免移动端耗电；大依赖按需加载。用有意义的测试覆盖未知参数、类别隔离、承重限制、恶意链接、持久化恢复、撤回与删除、三维尺寸不能泄漏成运输规格。浏览器验证桌面和手机视口，实际操作旋转、缩放、换辅具、改尺寸、刷新恢复及同页商品/出行流程，记录 WebGL 降级与未完成的人工读屏验收。完成本地可运行版本后复用现有免费魔搭创空间发布流程，若需要部署令牌，只在本地密码框输入，不在聊天或源文件中保存。
