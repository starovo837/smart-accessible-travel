# 分类辅助平台

首页“我的辅助组合”可多选视障、听障、肢体、言语、认知、慢病。选择只影响推荐顺序，不限制使用其他功能。多个类型的首要工具会先各展示一项，避免通用工具挤掉某种需要。未选择者可自由浏览。辅助类型只在个人档案授权后保存。

| 需要 | 优先入口 | 实现 |
|---|---|---|
| 视障 | 看图读字、放大镜、颜色与明暗 | 现有本地/创空间 Qwen3-VL、浏览器 Canvas、文字朗读 |
| 听障 | 打字沟通、沟通卡、基础手势 | 文字输入、沟通卡、MediaPipe 本机模型 |
| 肢体 | 辅具专业服务、居家与设备、三维试配 | 键盘与大按钮、现有设备工具 |
| 言语 | 打字朗读、常用话语、手势短语 | 本机文字转语音、大字卡、7种静态手势 |
| 认知 | 一步一步做、时钟、提醒 | 任务模板、自定义步骤、可暂停进度、真实系统时间 |
| 慢病 | 自设提醒、设备照护与出行 | 本人已有安排、设备事项、原有出行核验 |

所有工具从“辅助中心 → 全部功能”可见。首页保留三维试配、买辅具、出行查询与文字助手，各自独立页面。老年模式、字号、朗读、减少动画仍可自由组合，摄像头只在本人主动开启后使用。

## 真实能力与边界

- 图像阅读只在本人确认本次图片处理后调用既有开源模型。图像任务有会话隔离、进度、取消和总时限；没有模型时明确报错，绝不替换成固定答案。图片只留在当前页面和临时模型任务中，不写长期档案。它不能判断道路安全、距离、用药或医学适用性。
- 手势采用 MediaPipe Tasks Vision 1.1.1，运行脚本、WASM与官方模型随应用提供，不依赖运行时海外 CDN。摄像头识别需连续稳定3帧且分类分数不低于0.7；朗读前由本人确认。照片单帧结果同样需要确认。手势练习与可自设短语已实现，不声称完整中国手语翻译。
- 2026-10-27按用户要求移除全部语音输入：首屏语音演示、助手录音与识别确认、日常语音转写、实时字幕、语音操作及相关设置。保留18项辅助工具和文字助手；文字朗读、沟通卡及朗读开关继续保留。旧字幕与语音操作链接进入辅助中心，旧语音入口偏好在保存与恢复时清理。
- 摄像头仅在主动开启后使用；工具卸载、退出与进入后台时停止轨道。放大镜和颜色/明暗均在本机处理，不提供避障能力。
- 任务、提醒、常用话语和手势短语遵循已有生活资料授权。关闭授权或删除生活资料会清除相应持久副本。提醒只在应用打开时显示，不宣称关闭网页后有后台推送。药物名称和时间仅能来自本人已有安排，不提供药物或剂量建议。

## 体重与三维外形

原来体重仅用于承重比较。现增加连续、有界的外观体积变化：身高与体重影响躯干及四肢的近似外观，骨骼长度不随体重改变。已填臀宽、肩宽、腕围和踝围优先保护；不从体重填出任何实测围度，不把体重变成设备重量或出行规格。空白或无效体重仍采用示例外观。画面明确说明不是本人扫描或医学适配。

## 本地验收

- 多类型首页推荐、18个全部功能入口、自由进入其他类型工具。
- 官方 `thumb_up.jpg` 经真实本机 MediaPipe 模型识别为 Thumb_Up；手势练习匹配。

- 放大镜选图、缩放、反色；提醒新增、到期、完成；文字输入与短语操作。
- 320px与200%字号、工具返回、摄像头关闭、任务恢复、键盘操作和完整自动化回归。自动化不代表真人读屏、真实场景手语或医疗适配验收。
