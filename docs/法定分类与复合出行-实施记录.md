# 法定分类与复合出行

## 2026-11-14 本机实现记录

- 中国残联分类与分级全文已通过 Agent Reach 网页渠道读取。
- 标准公开状态：GB/T 26341-2010，现行。
- 六个基础类别可多选；多重残疾为派生摘要。
- 等级、陪同与已有辅具引用在本机独立保存；删除全部资料会删除该记录。
- 旧认知、慢病辅助标签不被自动认定为法定类别。
- 六类协助建议各十项；覆盖 A–E。
- 六组组合各有两项替代建议，展示原提醒与替代原因。
- 视力及听力同时存在时使用单独的人工交接建议。
- 一次只做一步的顺序使用安全、申请、通行、沟通、信息。
- 组合建议是待运营方确认的协助请求，不是运输安全许可。

## 已验证

固定行程：高铁，上海虹桥至杭州东。

1. 肢体一级、手动轮椅、独立出行。
2. 肢体一级、手动轮椅、需要陪同或监护。
3. 视力一级。
4. 听力一级。
5. 言语二级。
6. 精神三级。
7. 视力一级与听力一级。
8. 肢体一级、视力一级与言语二级。

自动测试检查确定性、实际行动数量、八组两两差异、陪同差异、组合数量、官方核验入口与占位符。

Chrome 390×844：类别可多选，组合摘要显示，两条组合建议可见，刷新恢复，无应用运行错误。

## 后续工程整改结果

- 已接入结构化冲突检测：通道、流程、相反指令；关联冲突原子替换。
- 冲突条目保留原证据，流程冲突保留提前办理时间。
- 95 个源文件的 3977 条文案迁入独立字典。
- 字典全部条目禁用词检查通过。固定八组导出与随身卡检查通过。
- 八组行动正文和可复制话术按句检查不超过 30 字。
- 法定声明、外部原文、产品原始资料和完整名称保留；不截断事实。
- 文案迁移前后 3977 条静态文案的数字及 URL 比较无差异。
- 已修复选择陪同时残留“独自出行”的旧话术。
- 不携带辅具的非肢体类别不会被要求填写轮椅尺寸和电池。
- 浏览器验证朗读函数被调用一次且内容包含 A–E 五段。
