# 分类工作台与校园主题

首页打开即进入工作台，按6类展示26个可操作入口，保留全部18项辅助工具。每项入口连接既有真实页面或设置，不新增虚构服务。辅助组合可在“我的与设置”调整；不填写个人情况仍能使用，保存范围继续受原有隐私授权控制。删除全部数据后回到空白资料的工作台。

标准手机显示4列图标，320px显示3列，放大字号或老年模式降为2列。类别为辅具与出行、阅读与沟通、生活与健康、办事与参与、地图与求助、我的与设置。老年模式和朗读开关统一在辅助设置中保留。所有语音输入继续移除，助手只接收文字。

页面采用真实东南大学四牌楼校区大礼堂及喷泉照片，首页头部以淡色遮罩保留取景，其他页面铺低饱和淡白背景；文字和表单本身不透明度不变。三维模型及交互画布保留中性舞台，页面外围使用校园背景。高对比系统模式关闭装饰背景。离线应用内嵌照片，服务工作线程也缓存照片，避免国内网络运行时依赖外网图库。

图片作者：猫猫的日记本；摄于2012-09-11。来源：https://commons.wikimedia.org/wiki/File:Auditorium_and_Fountain_in_Southeast_University_2012-09.JPG 。许可：CC BY-SA 3.0，https://creativecommons.org/licenses/by-sa/3.0/ 。原文件保留，视窗仅用CSS缩放/裁切和淡色层；许可文件随public图片发布，“我的”页面提供作者与许可链接。无学校或作者背书。

校徽点缀：使用东南大学官网 https://www.seu.edu.cn/p47316c47313/list.psp 提供的578×578透明PNG原图，保留黄绿原色、比例和完整图形；在工作台、欢迎页及主要功能顶部单独展示，与软件自身AppMark分开。校徽链接可查看官方说明；“我的”页面不设置校园介绍区块。来源及版权归属记录见public/images/seu-emblem.SOURCE.txt；校徽不适用校园照片的CC许可。素材随应用与离线版本本地提供，不依赖运行时访问校网，不声明学校官方运营或背书。

设计参考：用户提供的分类工作台截图；完整视觉概念见design/workbench-campus-concept.png。概念由内置Image Gen以用户布局截图及上述真实照片作参考生成，仅用作设计说明；产品背景使用原始实景照片。界面保持原AppMark；末组5项采用4+1换行，避免概念图5列挤小文字。核心图标沿用现有语义SVG图标系统。

设计约定：深绿文字、浅白分类面板、淡绿图标底与小金色强调，分类标题与图标标签原生排版。桌面仍保持移动App容器，手机触控至少48px。主标题“工作台”，副文“按分类，找到现在需要的帮助。”；不增加状态数字、虚构数据或演示服务入口。


本地验收：185项自动化测试通过；26入口逐个实际点击并检查对应页面或对话框，390px四列、320px三列、老年模式与200%字号两列通过。主标题和图标名称范围检查未发现横向裁切；照片实际加载尺寸4320×3240，所有页面图片地址与许可入口已核对。使用独立Playwright Chrome测试（当前无Browser插件），麦克风/语音识别接口访问0，页面错误0。真实用户手机与读屏仍需人工验收。

视觉核对：已以view_image对比完整概念与浏览器截图，检查分类顺序、26条文案、面板与图标结构、深绿/浅白配色、真实照片取景和淡化、手机换列、底部导航。保留原AppMark而不采用概念叶形标记；末组4+1和放大字号2列是触控/文字可读性所需的响应式差异。首屏不显示大段技术说明，资料处理说明仍在使用相应功能时提供。
