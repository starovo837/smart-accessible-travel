# 分类工作台与校园主题

首页打开即进入工作台，按6类展示26个可操作入口，保留全部18项辅助工具。每项入口连接既有真实页面或设置，不新增虚构服务。辅助组合可在“我的与设置”调整；不填写个人情况仍能使用，保存范围继续受原有隐私授权控制。删除全部数据后回到空白资料的工作台。

标准手机显示4列图标，320px显示3列，放大字号或老年模式降为2列。类别为辅具与出行、阅读与沟通、生活与健康、办事与参与、地图与求助、我的与设置。老年模式和朗读开关统一在辅助设置中保留。所有语音输入继续移除，助手只接收文字。

## 0.6.1 校园封面

各页使用同一张东南大学四牌楼校区照片。首页全宽封面从工作台顶部贴边开始，高度为 `clamp(320px, 56svh, 540px)`。品牌、标题和副标题位于封面底部的纸色遮罩上。最后 48px 渐变到纸面。桌面两侧显示静态原图，喷泉动效只在首页封面内。正文、表单和导航仍使用浅色纸面。离线应用使用同一份原图。

在「我的 → 辅助设置」关闭「背景水景动效」，封面只显示静态照片。「减少动画与滚动效果」、系统减少动态（`prefers-reduced-motion`）、省流量、老年模式和系统高对比度也会停用水景及页面入场。标签页进后台或封面离屏时暂停并清空画布。应用将开关保存在本机。

开发服务器的 `?calibrate=fountain` 可以拖动原图上的喷口及池面线，也可用数字输入调整。封面预览支持宽度、高度和照片纵向位置调整。标定结果按 4320×3240 原图归一化，依次是主水柱底部 `(0.450, 0.609)`、左侧低喷口 `(0.238, 0.794)`、右侧低喷口 `(0.766, 0.806)`，池面基线为 `0.859`，默认纵向裁切为 `0.50`。照片与喷口、池面共用 `cover` 换算。生产构建不含标定工具。

画布按封面面积绘制 180–260 个水滴，用 64×64 径向渐变贴图绘制柔边与短拖尾。底部有 11 团薄雾、3 圈错时涟漪和缓慢变化的落水光晕。画布上限为 30fps，DPR 不超过 2。

- 320×740、390×844 与 1440×900 的封面分别约为 414、473、504px，均约占视口 56%。320px 首屏完整显示前三项，第四项部分露出；390px 和桌面完整显示四项。标题、品牌、说明和首个入口文字的最低对比度为 5.96:1。
- 本地 Chrome 采样约 22fps，三档绘制耗时 P95 不超过 1.2ms。未观察到采样期长任务。320px 放大到 200% 字号后无横向滚动。
- 官方 npm CLI 执行的 `npm run build` 与两个文案守卫均已通过，`node --test tests/*.test.mjs` 通过 345 项。Chrome 和 WebKit 各跑通买辅具、出行查询、文字助手、生活、辅助中心、我的六页，并在入场动画中点击返回。动效开关、系统及应用减少动画、老年模式、省流量、高对比度均保留静态封面。
- 截图保存在本地检查点，未随生产包上传。0.6.1 的本地检查和魔搭发布单独记录。

普通页面入场 240ms，出行与商品输入页 160ms。底部光晕在 600ms 内淡出，透明度最多 0.08。按钮、滚动及键盘导航在入场期间可用。

`node scripts/assert-plain-copy.mjs` 检查界面文案字典，禁用词包括「核验、复核、快照、闭环、赋能、抓手、颗粒度、适用范围」。文案变更保留日期、官网链接及承运方书面确认提示。`npm run build` 同时运行文案守卫与出行文案测试。

本地验收：185项自动化测试通过；26入口逐个实际点击并检查对应页面或对话框，390px四列、320px三列、老年模式与200%字号两列通过。主标题和图标名称范围检查未发现横向裁切；照片实际加载尺寸4320×3240，所有页面图片地址与许可入口已核对。使用独立Playwright Chrome测试（当前无Browser插件），麦克风/语音识别接口访问0，页面错误0。真实用户手机与读屏仍需人工验收。

视觉核对：已以view_image对比完整概念与浏览器截图，检查分类顺序、26条文案、面板与图标结构、深绿/浅白配色、真实照片取景和淡化、手机换列、底部导航。保留原AppMark而不采用概念叶形标记；末组4+1和放大字号2列是触控/文字可读性所需的响应式差异。首屏不显示大段技术说明，资料处理说明仍在使用相应功能时提供。
