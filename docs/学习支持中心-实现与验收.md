# 学习支持中心：实现与验收

日期2026-11-16；版本0.5.0。范围仅限学习支持区域、入口、保存/导出边界及相关文档。原出行A–E结构、完成度、来源、电话与话术不变。

## P0

- `src/app/learningCatalog.ts`：18资源，六类各3；源页、日期、90天复核、适用范围、费用/账号边界、无障碍能力的“有说明/未确认”、地区与替代路径。
- `src/features/learning/LearningCenter.tsx`及独立CSS：搜索/组合筛选/排序、收藏、打开、朗读、来源、问题标记、空结果三步卡。
- 首页工作台单击进入；工作场景顶部有三张资源预览与查看全部；原参与需求卡和记录保留。原服务卡增加可见核验日期；服务目录26条。
- 问题反馈只记本机，不声称已提交给维护者。不自动改变全体用户目录状态；后续维护者复核来源后更新目录。

## P1

- `learningPlan.ts`：先选目标类别，填写目标/原因/每周时间，选1–3资源，创建四步学习计划，复用`assistance.tasks/progress/reminders`。
- 完成、撤销完成、笔记即时更新；经既有生活保存授权才能写localStorage。与逐步任务双向读取进度。
- 站内提醒与ICS日历导出；网页关闭不保证提醒送达。日历仅“学习时间”，不带目标、笔记和个人情况。
- TXT离线清单和SVG随身卡仅含公开资源、固定步骤、进度与来源。笔记、目标原文和障碍类型不导出；普通生活分享/独立包也排除学习记录及关联任务/提醒。
- `learningGuides.ts`：12项申请沟通模板，各有适用场景/受理方/期限/材料/话术/官方来源；6张现有工具教程。未复制课程或教材，不保证获批。
- 撤回生活保存时清除学习记录、步骤和提醒；单计划删除仅清相应内容；全部清除沿用既有删除入口。

## 核验方式

使用Agent Reach网页渠道读取NVDA、争渡、智慧教育、教育部高考便利规定、清华平台介绍等；同时使用公开网页读取对照官方介绍、服务声明、版权声明和机构页。逐条结果见台账。`verified`只指入口与公开范围已核对，不代表登录/实名/报名/价格/无障碍实机测试通过。`reviewDueAt`早于当天即显示需复核，保留原入口与备用咨询方式。

## 自动化与人工检查

- 新增`tests/learning.test.mjs`覆盖18条完整性、六分类、来源与HTTPS白名单、日期/过期、组合筛选、确定性推荐、收藏、计划创建/保存恢复、权限撤回、删除关联任务、提醒到期、导出不带敏感信息、12模板/6教程。
- `npm run build`必须包括出行文案断言、TypeScript与Vite；`node --test tests/*.test.mjs`检查既有回归。
- 浏览器检查入口、筛选、空结果、收藏、计划、刷新、笔记、提醒、下载、删除和键盘；320px、200%字号无横向溢出；点击才朗读。
- 真实读屏、真人键盘独立操作、iOS/安卓微信浏览器、真实手机日历导入以及第三方登录后的课程表现仍需人工验证，不能以模拟视口冒充实机测试。

### 人工验收清单

1. 首页打开学习支持中心；键盘到达搜索、筛选、每张卡的各项操作。
2. 找“NVDA”，再筛字幕，看到真实空结果与替代咨询；取消筛选后恢复18条。
3. 创建一个本地计划；勾选进度、写合成笔记、刷新恢复；到逐步任务核对同一进度。
4. 设置一分钟后提醒；网页运行时查看到期；导出ICS并在手机手动导入。
5. 导出TXT与SVG，核对不含笔记/目标原文/障碍类型；勾选两项便利模板并导出。
6. 关闭生活保存，学习计划、收藏和学习提醒清空，刷新后不会回来。
7. 实际读屏读出资源标题、支持未确认、日期、展开状态、按钮名称与结果数量。
