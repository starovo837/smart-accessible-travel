# 魔搭创空间发布

账号已确认是 `starovo`。浏览器登录状态不能替代命令行上传授权。

## 先检查账号（只读）

1. 在浏览器打开 [魔搭访问令牌](https://modelscope.cn/my/settings/token)。使用你自己的访问令牌；发布时需要对应仓库的写入权限。不要把令牌发到聊天里。
2. 按 `Win + E` 打开文件资源管理器，在地址栏输入 `D:\Codex\projects\New project`，双击 `检查魔搭部署.cmd`。不需要管理员权限。聊天中的文件链接通常会打开代码预览，脚本需在文件资源管理器中运行。
3. 在弹出的「智能无碍行 · 魔搭令牌输入」密码框粘贴令牌，点击「继续配置」。输入隐藏属正常现象；不要粘贴到黑色窗口或聊天中。
4. 脚本验证账号，查询 Docker 可用硬件，在项目根目录生成 `.studio-check.json`。它不含令牌，可将该文件或资源结果交给助手。

新版输入框兼容复制时附带的末尾换行，以及标准令牌中的 `+`、`/`、`=`；仍会拒绝遮盖圆点、网址、中文提示和令牌中间的空白。若看到旧黑色窗口的 `Invalid token format`，请使用新打开的中文输入框。在令牌页点击“两张重叠方框”复制图标（眼睛图标左侧），不要框选遮盖圆点后复制。无需重建令牌。

令牌只暂存在该进程内存，不写入 `.env.local`、代码、Git 地址或创空间变量。不要截图或发送包含令牌的页面。

## 核实资源后发布

助手依据实时返回的硬件列表准备 `.studio-deploy-plan.json`，写明账号、创空间名称、免费硬件和公开范围。发布脚本拒绝收费资源及计费属性不明确的资源。

配置核对后，在项目根目录双击 `发布到魔搭创空间.cmd`，再次在本地隐藏输入同一个令牌。无需新建令牌。检查脚本完成后已清除凭证，因此发布仍需你输入一次。脚本整理白名单源文件、扫描疑似凭证、创建或更新本作品的 Docker 创空间、普通 Git 推送并请求构建。已有同名但无法识别为本作品的仓库不会被覆盖；不使用强制推送。

发布脚本会继续读取构建与运行状态，最多检查30分钟，把不含凭证的结果保存在项目根目录 `.studio-status.json`、`.studio-publish-result.json` 和 `.studio-logs/`，便于助手排错。无需手动复制大段日志。容器 Running 不代表模型实际解读已通过。

没有免费 GPU 时需先评估 CPU 推理速度或申请平台免费算力，不能保证图文 AI 能在所有免费规格下运行。不要为了通过构建就把模型替换成预置答案。

## 发布成功的标准

- 魔搭显示 Running，基本页面通过公网 HTTPS 加载。
- 首次模型下载完成，AI 状态显示就绪。
- 用新的公开商品文字和图片实际解读成功，原文依据可核对。
- 手机通过公网链接能使用，不依赖这台电脑开机或同一 Wi-Fi。
- 在线版上传前显示服务端处理提示，配对与本机管理端点关闭。

完成以上检查后，才将实际创空间链接填入比赛的“应用（创空间）”栏。账号个人中心链接不能作为作品体验链接。

本作品已创建的创空间是 [智能无碍行](https://modelscope.cn/studios/starovo/smart-accessible-travel)，直接运行地址为 [在线应用](https://starovo-smart-accessible-travel.ms.show)。创建成功与在线验收通过是两个状态，请以最新构建及实际解读检查为准。比赛表单填写前一个创空间链接。模型、数据集、Notebook、MCP、Skill 等可选栏，未单独发布对应资源时留空；无需为了填写这些栏新建资源。

手机可使用[全屏体验入口](https://www.modelscope.cn/studios/starovo/smart-accessible-travel?mode=full)。已验证 Android 浏览器模拟下该入口按手机宽度显示；真实手机读屏等能力仍需人工验收。

若页面可打开、模型显示就绪，但提交出现“请从软件本身提交资料”，应核对平台变量 `SAI_PUBLIC_ORIGINS` 是否为 `https://starovo-smart-accessible-travel.ms.show`。本地配置动作 `run-platform.ps1 -Action configure` 只设置本作品的准确域名并请求配置生效，不做 Git 代码上传或硬件变更。无需关闭来源检查或允许任意域名。

参考：[魔搭官方创空间部署说明](https://github.com/modelscope/modelscope-skills/blob/main/skills/ms-studio-deploy/SKILL.md)。
